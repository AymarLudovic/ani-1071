Essais :
1/2 + 1/3 = 5/6
1/2 - 1/3 = 1/6
2/3 * 9/4 = 3/2 (le resultat est reduit)
3/4 / 2/5 = 15/8
2/-6 = -1/3 (le denominateur est rendu positif)

Égalités :
Fraction(1, 2) == Fraction(2, 4) : true, car les deux objets sont normalises en 1/2.
Fraction(1, 2) == Fraction(3, 4) : false.

Dénominateur nul :
Fraction(1, 0) declenche une exception `invalid_argument` avec le message `denominateur nul interdit`.
La division par Fraction(0, 1) declenche une exception `invalid_argument` avec le message `division par une fraction nulle`.
Le choix est de refuser ces deux cas avec une exception : une fraction ne peut pas avoir un denominateur nul, et une division par zero n'est pas definie. Le programme intercepte les exceptions et affiche les messages au lieu de s'arreter brutalement.

Invariant :
Le constructeur refuse d'abord d = 0. Si d est negatif, il change les signes du numerateur et du denominateur pour rendre le denominateur positif. Il calcule ensuite le PGCD par l'algorithme d'Euclide avec le reste `%`, puis divise les deux membres par ce PGCD.
Tous les operateurs construisent leur resultat avec `Fraction(...)` : le constructeur reduit donc aussi chaque resultat et conserve l'invariant. Deux fractions egales ont alors le meme numerateur et le meme denominateur, ce qui permet a `==` de comparer directement les deux membres.
