Message :
Avec `const Chrono k;`, l'appel `k.redemarrer();` est refuse. Message Clang observe :
error: 'this' argument to member function 'redemarrer' has type 'const Chrono', but function is not marked const

Pourquoi :
`k.ecoule()` passe parce que `ecoule()` est declaree `const` : elle lit l'instant de depart sans modifier l'objet.
`k.redemarrer()` est refuse parce que `redemarrer()` change le membre `depart`. Une methode non const ne peut pas etre appelee sur un objet declare const.
